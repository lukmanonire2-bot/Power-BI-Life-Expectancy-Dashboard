# Power-BI-Life-Expectancy-Dashboard
Male and Female Life Expectancy at Age 60

ASA International Data Quest 2026

Project Overview

This project involved analysing demographic data to explore birth trends and life expectancy at age 60 across different countries.

The dashboard was developed using Microsoft Power BI to present demographic indicators through interactive visualisations.

Key Performance Indicators

* Total Number of Births: 35.636K
* Average Life Expectancy at 60: 20.68
* Female Life Expectancy at 60: 22.04
* Male Life Expectancy at 60: 19.21

Dashboard Visualisations

* Yearly Birth Trend
* Life Expectancy at 60 Trend by Sex
* Top 10 Life Expectancy at 60 by Country
* Top 10 Births by Country

Tools Used

* Microsoft Power BI
* Data Analysis
* Data Visualisation

Project Objectives

1. Examine birth trends over time.
2. Compare male and female life expectancy at age 60.
3. Identify countries with higher life expectancy at age 60.
4. Explore differences in birth figures across countries.
5. Communicate demographic insights through visualisation.

Key Observation

The dashboard indicates that female life expectancy at age 60 (22.04 years) is higher than male life expectancy (19.21 years).

Experience

This project was undertaken as part of the ASA International Data Quest 2026, providing an opportunity to apply data analytics and visualisation skills to demographic data.

Conclusion

The project demonstrates how Power BI can be used to transform demographic data into meaningful visual insights that support statistical interpretation and informed decision-making.
